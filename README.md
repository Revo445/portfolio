# Revo — Portfolio

Static portfolio site (plain HTML + CSS, no build step).

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Enable GitHub Pages: repo Settings -> Pages -> Deploy from branch -> `main` / root.
